# Challenge Introduttive — CyberChallenge 2025/2026
 
Questo ramo contiene le challenge introduttive affrontate durante il percorso CyberChallenge 2025/2026.
Le challenge sono organizzate per categoria, ognuna con i relativi file di soluzione e writeup.
 
## Struttura
 
```
.
├── NetworkSecurity/       # Challenge di sicurezza di rete
├── WebSecurity/           # Challenge di sicurezza web
├── Cryptography/          # Challenge di crittografia
└── SoftwareSecurity/      # Challenge di sicurezza software
```
 
## Organizzazione delle cartelle
 
Ogni cartella di challenge segue questa struttura:
 
```
<NomeChallenge>/
├── testoChallenge.txt   # Descrizione della challenge e writeup
├── script.py            # Script o file di soluzione (se presente)
├── writeUp.txt          # Writeup e spiegazione della soluzione
```
 
## Categorie
 
### NetworkSecurity
Challenge relative all'analisi del traffico di rete, protocolli e sicurezza delle comunicazioni.
 
### WebSecurity
Challenge relative a vulnerabilità web come XSS, SQL Injection, CSRF e altre tecniche di attacco/difesa.
 
### Cryptography
Challenge relative a cifrari, hashing, crittografia simmetrica e asimmetrica.
 
### SoftwareSecurity
Challenge relative a vulnerabilità software, binary exploitation, reverse engineering e analisi statica/dinamica.
